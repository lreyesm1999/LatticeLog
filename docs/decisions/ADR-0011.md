# ADR-0011 — Security of the external MCP adapter

- Status: **accepted for the local stdio adapter** (2026-11-18) · Phase: P22

## Decision
- Read-only; 8 tools that reuse `QueryEngine`/`EvidenceService` (no duplicated logic).
- Bound to **one store fixed at startup**: no tool accepts paths (no path traversal).
- stdio transport only (minimal exposure). Remote HTTP is not allowed until there is robust authentication (P18).
- Per-session limits: 500 calls, 8 MiB of responses, a 256 KiB budget per call, 200 events per search, 30 s query
  timeout.
- Every output includes `coverage` and `trust.untrusted_fields`; `_meta.untrusted_content = true`; redaction applied.
- Negotiated protocol versions: `2025-11-25`, `2025-06-18`, `2025-03-26`. **Open (P22-T01)**: verify against the
  current MCP specification (the plan cites 2026-07-28) and update the list; no official conformance suite has been run.

## Residual risks
A client with access to the process can read the whole store (there is no per-field RBAC locally). The server uses
per-namespace scopes; time-limited tokens are still open (P18-T07).
