# ADR-0011 — Seguridad del adaptador MCP externo

- Estado: **aceptada para el adaptador local stdio** (18-nov-2026) · Fase: P22

## Decisión
- Solo lectura; 8 herramientas que reutilizan `QueryEngine`/`EvidenceService` (sin lógica duplicada).
- Ligado a **un almacén fijado al arrancar**: ninguna herramienta acepta rutas (sin path traversal).
- Transporte solo stdio (exposición mínima). HTTP remoto queda prohibido hasta tener autenticación robusta (P18).
- Límites por sesión: 500 llamadas, 8 MiB de respuesta, 256 KiB de presupuesto por llamada, 200 eventos por búsqueda,
  timeout de consulta 30 s.
- Toda salida incluye `coverage` y `trust.untrusted_fields`; `_meta.untrusted_content = true`; redacción aplicada.
- Versiones de protocolo negociadas: `2025-11-25`, `2025-06-18`, `2025-03-26`. **Pendiente (P22-T01)**: verificar
  contra la especificación MCP vigente (el plan cita 2026-07-28) y actualizar la lista; no se ha ejecutado una suite de
  conformidad oficial.

## Riesgos residuales
Un cliente con acceso al proceso puede leer todo el almacén (no hay RBAC por campo en local). En servidor se
requerirán scopes por tenant/proyecto y tokens de tiempo limitado (P18-T07).
