# ADR-0001 — .NET 10 LTS for the initial engine and SDK

- Status: **accepted** (2026-11-18) · Phase: P00-T13

## Context
The plan calls for a high-performance .NET SDK and a local engine. Alternatives: Rust/C++ (a native core with bindings)
or .NET.

## Decision
The initial engine, SDK, CLI, reader and server are written in C#/.NET 10 LTS. The `.llog` format is specified
independently of any language and validated with an independent Python reader.

## Rationale
- The first target SDK is .NET: the same platform means no interop cost on the hot path.
- `Span<T>`, `ArrayPool`, CRC intrinsics, Roslyn source generators and Native AOT allow near-native performance.
- 3 years of LTS support (until Nov 2028), revisited at every LTS release.

## Consequences
- Risk R07 (a format coupled to .NET) is mitigated by a public specification + golden files + `tools/pyllog`.
- SDKs in other languages are transport clients, not reimplementations of the engine (P21-T01).
- If future profiling shows that GC/JIT prevent the targets, a native core for the codec will be reconsidered.
