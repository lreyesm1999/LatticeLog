# ADR-0001 — .NET 10 LTS para el motor y SDK iniciales

- Estado: **aceptada** (18-nov-2026) · Fase: P00-T13

## Contexto
El plan exige un SDK .NET de alto rendimiento y un motor local. Alternativas: Rust/C++ (núcleo nativo con bindings) o .NET.

## Decisión
Motor, SDK, CLI, lector y servidor iniciales en C#/.NET 10 LTS (SDK 10.0.404 instalado por usuario en esta máquina).
El formato `.llog` se especifica de forma independiente del lenguaje y se valida con un lector Python independiente.

## Justificación
- El primer SDK objetivo es .NET: misma plataforma = sin coste de interop en la ruta caliente.
- `Span<T>`, `ArrayPool`, intrínsecos de CRC, generadores de código Roslyn y Native AOT permiten rendimiento cercano a nativo.
- Soporte LTS de 3 años (hasta nov-2028), revisable en cada versión LTS.

## Consecuencias
- Riesgo R07 (formato acoplado a .NET) mitigado con especificación pública + golden files + `tools/pyllog`.
- Los SDK de otros lenguajes serán clientes de transporte, no reimplementaciones del motor (P21-T01).
- Si un perfilado futuro demuestra que GC/JIT impiden los objetivos, se reevaluará un núcleo nativo para el códec.
